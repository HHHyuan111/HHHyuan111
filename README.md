# 电机控制研发工作台

电机控制 · 嵌入式开发 · MATLAB / Simulink · 上位机工具

## 研发项目

| 项目 | 用途 | 开发基础 |
| --- | --- | --- |
| [eMotor-Studio](https://github.com/HHHyuan111/eMotor-Studio) | 电机控制上位机、波形监控与实验分析工具，当前使用 MockBackend | 自建项目 |
| [Simulink](https://github.com/HHHyuan111/Simulink) | 电机控制仿真、MATLAB R2026a 模型适配与验证 | 基于 [Electric-Machine-for-Sharing](https://github.com/Sheeper-Xu/Electric-Machine-for-Sharing) 开发 |
| [AxDr_L](https://github.com/HHHyuan111/AxDr_L) | AxDr 学习板固件与电机控制实验 | 基于 [disnox/AxDr_L](https://github.com/disnox/AxDr_L) 开发 |
